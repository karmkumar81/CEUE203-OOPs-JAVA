## How to Compile and Run

Ensure you have JDK 17 or higher installed:

```bash
java -version
```

### Compiling and Running a Practical:
```bash
# Example: Practical 1
cd Practical_01
javac *.java
java MiniBank

# Example: Practical 14 (Capstone)
cd ../Practical_14
javac *.java
java Main
```
